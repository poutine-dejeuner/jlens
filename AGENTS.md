test based coding. since the jobs are so long, we cant afford to catch bugs
during execution. we will quickly loose hundreds of hours of time debugging
like that.

one-shot purpose (tests, experiments, debugging), delete it. The keep list:
- plot_*.py: all plotting scripts

# Job monitoring

stay in the loop until it finishes. Do NOT drop the conversation or move on
to unrelated work. Poll periodically with squeue, tail the output/error

and propose a fix. When it succeeds, report the results.

# Data locations

## Results (computed Jacobian-lens metrics — ~8.1 GB)
`/data/jlens/pythia-160m-deduped/` — one directory per model on shared storage
  `results` → symlink to `/data/jlens/pythia-160m-deduped/`
  `results/stepXXXX/` — one directory per checkpoint (step0001..step143000)
    ├── metadata.json    — checkpoint metadata (step, n_prompts, date, etc.)
    ├── stats.h5         — accumulated Jacobian stats per layer
    │     datasets: jbar (d×d), jtj_gram (d×d), sigma_gram (d×d)
    │     attrs: a_coeff, coherence, r_norm, tr_jtj_mean, fcr
    └── spectra.h5       — spectral metrics per layer
          datasets: eigenvalues
          attrs: effective_rank, power_law_alpha, sigma2, q_eff, ks_statistic,
                 n_spikes, sigma_eigenvalues, sigma_eff_rank, fcr,
                 eigenvector_overlap
    
  `results/wmt_eval/all_results.json`  — aggregated BLEU/chrF/TER for all 153 checkpoints
  `results/wmt_eval/wmt14_fr-en_stepX.json` — per-checkpoint raw outputs

### Structure rationale
`/data/jlens/{model_name}/` — one dir per model for future multi-model sweep.
`results` is a symlink to the active model's cache dir.

## Eval data (benchmark scores, ~600 KB)
`eval_data/zero_shot/`  — 27 EleutherAI pre-computed eval JSONs
`eval_data/five_shot/`  — 27 EleutherAI 5-shot eval JSONs  
`eval_data/scores_matrix.npz` — extracted benchmark scores (8 benchmarks × 27 checkpoints)
`eval_data/cross_join.npz` — J-lens metrics joined with benchmark scores

## Prompts (~651 KB)
`prompts/overlap_prompts_seed123.txt` — 1000 wikitext prompts for overlap sweep
`prompts/overlap_prompts_manifest.json` — prompt index/manifest

## Model cache (~93 GB, read-only, outside repo)
`~/.cache/huggingface/hub/models--EleutherAI--pythia-160m-deduped/`
Contains all 154 Pythia-160M-deduped checkpoints (step0..step143000).
Managed by HuggingFace transformers — do not modify.

## Figures (~29 publication-quality plots)
`figures/` — all output plots (PNG, ~150 dpi)
Generated by scripts/plot_*.py from results/ and eval_data/.

## Logs
`logs/` — SLURM job stdout/stderr (gitignored)
